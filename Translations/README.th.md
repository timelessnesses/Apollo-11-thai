ซอร์สโค้ดต้นฉบับของคอมพิวเตอร์นำทาง Apollo 11 (AGC) สำหรับโมดูลบัญชาการ (Comanche055) และโมดูลดวงจันทร์ (Luminary099) ไดัเปลี่ยนเป็นดิจิตัลโดยผู้คนจาก [Virtual AGC][3] และ [MIT Museum][4]
เป้าหมายคือการเป็นที่เก็บสำหรับซอร์สโค้ดต้นฉบับของ Apollo 11 ดังนั้น PR จึงยินดีต้อนรับสำหรับปัญหาเกี่ยวกับการการถอดข้อความจากรูปภาพในที่เก็บซอร์สโค้ดออนไลน์นี้และการสแกนซอร์สต้นฉบับสำหรับ [Luminary 099][5] และ [Comanche 055][6] และไฟล์ใดๆ ที่พวกเราพลาดไป

## การมีส่วนร่วมสนับสนุน

กรุณาอ่าน [CONTRIBUTING.md][7] ก่อนสร้าง Pull Request

## การคอมไฟล์

ถ้าคุณสนใจที่จะคอมไพล์โค้ดต้นฉบับของซอร์สโค้ดต้นฉบับของ Apollo 11 คุณสามารถดูได้ที่ [Virtual AGC][8]

### สัญญาและการอนุมัติ

*ได้ดัดแปลงมาจาก [CONTRACT_AND_APPROVALS.agc]*

โปรแกรม AGC อาจจะเรียกได้อีกอย่างว่า **Colossus 2A**

โปรแกรมนี้มีวัตถุประสงค์ใช้งานบน **โมดูลบัญชาการ (Command Module)** ตามที่ระบุในรายงาน `R-577`
จัดทำภายใต้โครงการ DSR หมายเลข `55-23870` สนับสนุนโดย Manned Spacecraft Center แห่ง NASA ผ่านสัญญา `NAS 9-4065` กับ Instrumentation Laboratory, Massachusetts Institute of Technology, Cambridge, Mass.
